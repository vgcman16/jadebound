# River Warden art direction

`river-warden-direction.png` is an original AI-generated concept sheet, explicitly labelled NOT IN-GAME. It is an aspirational design reference, not a screenshot or implemented 3D asset, and its views are not precise orthographic construction drawings.

The current procedural hero is a functional rig/equipment prototype. Reaching this direction requires a better anatomical base, bespoke fitted garment/armor forms, deliberate UV painting and bakes, and renewed deformation/animation review. Subdividing or adding bands to the current generator is not a credible substitute.

Preserve the equipment slot/clip/export contracts, but trial replacement art separately until an untextured body/outfit and a single surfaced pose meet the visual target. Any adopted base must have verified license/provenance, and must not be described as wholly original geometry.

No reference-game assets or supplied reference pixels were used to generate this concept. No output is promised to exactly reproduce it.
